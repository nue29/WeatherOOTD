# 오늘 뭐입지? (WeatherOOTD)

> 읍/면/동을 검색하면 앞으로 6시간 날씨와 대기질을 보여주고, 지금 기온에 맞는 옷차림을 추천하는 웹사이트를 기획하였습니다.

🔗 **Demo**: https://nue29.github.io/WeatherOOTD/

## 주요 기능

- **지역 검색**: 읍/면/동 이름으로 검색합니다. `사직동`처럼 이름만 입력해도 되고, 이름이 같은 동이 여러 곳이면 `중구 중앙동`처럼 시/군/구를 함께 입력해 구분할 수 있습니다.
- **현재 날씨**: 기온, 하늘 상태(맑음·구름많음·흐림), 비/눈 여부를 아이콘으로 보여줍니다.
- **시간대별 예보**: 이후 5시간의 기온, 하늘 상태, 강수 형태, 1시간 강수량을 보여줍니다.
- **대기질**: 해당 시/도의 통합대기환경지수 등급(좋음·보통·나쁨·매우나쁨)을 보여줍니다.
- **옷차림 추천**: 현재 기온 구간에 맞는 옷차림 이미지를 보여줍니다.

| 기온 | 28℃ 이상 | 23~27℃ | 20~22℃ | 17~19℃ | 12~16℃ | 9~11℃ | 5~8℃ | 4℃ 이하 |
|---|---|---|---|---|---|---|---|---|
| 이미지 | hot | warm | mild | cool | chilly | cold | verycold | freezing |

## 기술 스택

- HTML, CSS, JavaScript (Vanilla)
- Bootstrap 5
- [SheetJS (xlsx)](https://sheetjs.com/): 지역별 격자 좌표 엑셀 파일 파싱
- GitHub Pages 배포

## 사용한 API

| API | 용도 |
|---|---|
| [기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do) – 초단기예보조회 (`getUltraSrtFcst`) | 격자 좌표(nx, ny) 기준 6시간 예보 |
| [한국환경공단 에어코리아 대기오염정보](https://www.data.go.kr/data/15073861/openapi.do) – 시도별 실시간 측정정보 (`getCtprvnRltmMesureDnsty`) | 시/도별 통합대기환경지수 등급 |

## 동작 방식

1. 페이지가 열리면 `data/location.xlsx`(기상청 제공 행정구역별 격자 좌표)를 읽어 읍/면/동 → 시/도, 격자 좌표 목록을 만듭니다.
2. 검색한 지역의 격자 좌표로 초단기예보를, 시/도 이름으로 대기오염정보를 요청합니다.
3. 초단기예보는 매시 30분에 발표되고 45분 이후 조회할 수 있어, 현재 시각에서 45분을 뺀 시각의 30분 발표분을 요청합니다.
4. 응답을 예보 시각별로 묶어 현재 날씨, 시간대별 예보, 옷차림 추천을 그립니다.

## 로컬에서 실행하기

엑셀 파일을 `fetch`로 불러오기 때문에 파일을 직접 열면(`file://`) 동작하지 않습니다. 로컬 서버로 실행해 주세요.

```bash
git clone https://github.com/nue29/WeatherOOTD.git
cd WeatherOOTD
python -m http.server 8000
# http://localhost:8000 접속
```

VS Code의 Live Server 확장으로 열어도 됩니다.

## API 인증키 설정

두 API 모두 [공공데이터포털](https://www.data.go.kr/)에서 활용 신청한 **일반 인증키(Encoding)** 를 사용합니다. 인증키는 `config.js`에서 관리합니다.

```js
// config.js
const SERVICE_KEY = '발급받은_일반_인증키(Encoding)';
```

- 정적 사이트라 인증키가 브라우저에 그대로 노출됩니다. 공공데이터포털 개발계정 키는 무료이고 일일 호출 수 제한이 있어 이 방식으로 사용했습니다.
- 인증키 활용기간이 끝나면 `기한 만료된 서비스키` 오류가 납니다. 공공데이터포털 **마이페이지 > 데이터활용 > Open API > 활용신청 현황**에서 연장 신청하면 됩니다.

```
├─ index.html      화면 구조
├─ style.css       스타일
├─ config.js       공공데이터포털 인증키

├─ data/
│  └─ location.xlsx  행정구역별 기상청 격자 좌표
└─ img/            날씨 아이콘, 옷차림 이미지
```
